# 运行手册

## 上线前检查

| 项 | 期望 |
|---|---|
| 容器 `RestartCount` | 0（>0 说明在反复重启） |
| 快速登录 | 宿主机重启后无需扫码，登录态自动恢复 |
| 端口 | 只绑 `127.0.0.1`，公网扫描应看不到服务 |
| 服务 | 两个 unit 都 `active`，timer 下一次触发时间正常 |
| 体检 | `healthcheck.py` 退出码 0，且不会触发服务重启 |

## 常见故障

| 现象 | 根因 | 处理 |
|---|---|---|
| 一直 `activating` / `NRestarts` 暴涨 | 裸进程没杀，PID 锁 | 先停裸进程，再 `daemon-reload` + 重启 |
| 重启后要扫码 | 快速登录参数没固化进容器启动命令 | 按 `pin-quicklogin.sh` 重建一次 |
| apt 超时 | 内网源解析到 CGNAT | 换可达镜像源 |
| 服务找不到配置 | systemd 不带 `HOME` | 补 `Environment=HOME=...` |
| 体检脚本把服务拖进重启循环 | 失败退出码被当成异常 | 用 `SuccessExitStatus=0 1` |

## 回滚

每次改配置前留一份 `.v<日期>` 快照；容器内登录态无法用脚本「回滚」，
只能重新快速登录或扫码。改动前先备份容器参数（`docker inspect` 输出落到文件）。

## 口径

所有「当前状态」类数字（容器状态、重启次数、剩余磁盘）都会随时间变化，
对外文档引用时必须带核对时间戳；本文件只写机制，不写实时数值。
